# Project Overview

GitHub Notifications は IntelliJ IDEA 上で GitHub の通知を閲覧・絞り込み・処理するためのプラグインプロジェクト。

Kotlin と IntelliJ Platform SDK により構成され、Tool Window を主たる UI として通知の一覧表示とフィルタリングを提供する。
